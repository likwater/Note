# 第九届全国密码技术竞赛

## 初赛

1. 团队合作答题
2. 初赛比赛时，是团队三个人同时做不同的试卷
3. 初赛成绩在决赛中占成绩的20%

## 复赛

1. 复赛作品评分项：
   1. 性能指标；
   2. 创新性、实用性、新颖性；
   3. 难度；
   4. 支撑材料；
   5. 设计报告
   6. 猜测每项分值分别为：40、15、15、15、15
2. 复赛作品：
   1. 提前找好要用的密码算法的论文（有最好没有也可以）和对应的项目源码可以提前准备复赛的作品，没必要等着比赛方放题。自拟题要提前把自己的题目想好，也可以试着投稿。如果是比赛方出的A类题，一定要提前抢，很快就会被抢完。A类题进决赛的概率更大
   2. 作品最好还是对现有的算法进行创新优化后再应用，不然在决赛很可能面对专家的灵魂拷问（你的创新点在哪里？我没看到你的创新点）
   3. 为了有对算法的创新优化，所以最好提前半年准备，因为其实自拟题就是无限制，一般都可以通过的，所以你可以提前很早做准备，对算法研究优化
   4. 作品没有创新会很难受，因为评委也会问得很刁钻，不然不知道问你什么，除非你的应用很新颖没有人想到过可以这么用（不要认为网上没查到就是没有人这么用，很有可能人家团队在用了只不过没有公布出来或者在国外发了论文但你自己没有查到）
3. 选比赛方的题进决赛的比例更大，总的大概是1/2多一些，自拟题的话只有1/4-1/3

## 决赛

1. 演讲时间一定**不能超时**！！！评委已经听了很多队的汇报了，已经很不耐烦了，心里想的都是结束，你要是再拖时只会让评委更不耐烦，同时看你不顺眼，极可能在后面的提问中刁难你（当然如果是第一个可能会好一些，但最好不要超时）。
2. 如果能讲的东西不多，宁愿少讲也不要多讲，多讲多错
3. 没做到的东西或不确定的东西一定不要说，这个比赛的评委很专业，他们懂得远远比你多（人家是专家，而你不是），不然很有可能被专家发现漏洞或问题
4. 场地一定要提前试好没有问题，一定要按照最后比赛时的方式尝试一遍，**一摸一样方式模拟一遍**！！！（我这次就是因为只是插u盘试了，没有连腾讯会议试一次，导致出问题了，出问题没多久后专家就已经极度不耐烦了）
5. ppt要做好，字不要太多，要突出重点（加粗或用标红），多放一些和内容主题相对应的图片（更加生动形象、美观）。
6. 对老师的提问可以提前准备一些问题对应的答案：
   1. 你们作品的创新点是什么？
   2. 你们作品的技术难点是什么？
7. 在复赛到决赛期间，还可以对作品优化的
