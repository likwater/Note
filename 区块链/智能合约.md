# 搭建hardhat
1. [https://hardhat.org/hardhat-runner/docs/getting-started#overview](https://hardhat.org/hardhat-runner/docs/getting-started#overview)hardhat官方手册
2. 下载npm和nodejs

```python
从Ubuntu标准的软件源安装1：

运行以下命令更新软件包索引，并且安装Node.js和npm：
sudo apt update
sudo apt install nodejs npm

安装完成后运行以下命令，验证安装过程：
nodejs --version

下载nodejs
Download the setup script for Node.js v14:
curl -fsSL https://deb.nodesource.com/setup_14.x | sudo -E bash -
Install Node.js:
sudo apt-get install -y nodejs
                       
更新nodejs
首先，清除npm缓存：
npm cache clean -f
全局安装n模块：
npm install -g n
使用n模块升级到最新稳定版：
n stable
以上命令将会自动下载并安装最新的稳定版Node.js1。                  

```
