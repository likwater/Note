## 应用

1. 应用场景：现有一个$e$阶的多项式$f$（在$Z_n$里面计算），那么可以：

   1. 给定$\beta$，快速求出模某个$b$意义下较小的根，其中$b\geq n^{\beta}$，$0<\beta\leq1$，是$n$的因数
   2. 在模n的意义下，快速求出$n^{\frac{\beta^{2}}{e}}$以内的根

2. sage：`small_roots(X = ,beta = )`

   1. X代表所需要求解根的上限，即求解的根在$[-X,X]$的区间内。虽然是根的上限，并不是说上限越高越好，当上限超过某个值的时候就会计算失效，即使已知二进制位数满足条件，也无法用此函数求得结果；所以一般来说X取在给定情况下的最大求解上限。

   2. beta即是前面提到的 $\beta $，当p，q二进制位数相同时一般只能取0.4

   3. 在X的区间内当模n下有解时，就只会返回模n下的解；当模n下无解时，就只会返回模某个$b$意义下较小的根（$b$是$n$的因数）

   4. 输出值都是正值，且在模n的群内。

      ```sage
      R.<x> = PolynomialRing(Zmod(n), implementation='NTL')
      p = high_p + x
      x0 = p.small_roots(X = 2^128, beta = 0.4)[0]
      
      PR.<x> = PolynomialRing(Zmod(12))
      f = x+4
      f = f.monic()
      f.small_roots(X=3, beta=0.4)  
      输出：[0, 2] #此时模12在[-3,3]无解， 模6和模4有解
      
      PR.<x> = PolynomialRing(Zmod(12))
      f = x+4
      f = f.monic()
      f.small_roots(X=4, beta=0.4)  
      输出：[8] #此时模12在[-4,4]有解，是-4即8
      ```

   5. 当未知量小于等于454bits时（p,q为1024bits），coppersmith定理可以求解

      ```sage
      from Crypto.Util.number import getPrime
      p = getPrime(int(1024))
      q = getPrime(int(1024))
      n = p * q
      test_bits = 454
      p_h = p >> test_bits
      R.<x> = PolynomialRing(Zmod(n))
      f = (p_h << test_bits) + x
      f.small_roots(X=2**test_bits,beta=0.4)
      ```
